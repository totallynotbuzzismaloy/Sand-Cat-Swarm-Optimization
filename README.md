# Sand Cat Swarm Optimization Based on Stochastic Variation With Elite Collaboration

Данная модификация алгоритма Sand Cat Swarm Optimization (SCSO) была выполнена на основе статьи:

> [A Sand Cat Swarm Optimization Algorithm for Solving Optimization Problems](https://ieeexplore.ieee.org/document/9864584), Zhang et al., IEEE, 2022.

В этой работе предложена базовая версия алгоритма SCSO, на основе которой были добавлены стохастические вариации и механизм коллаборации элитных особей для улучшения оптимизационных характеристик алгоритма. Настоящая модификация адаптирует предложенные идеи и расширяет их для повышения эффективности и надежности в условиях случайных вариаций.

## Описание модификации

В данной реализации введены следующие улучшения:
- **Стохастическая вариация** — позволяет моделировать случайные изменения в поведении агентов, улучшая поиск глобального минимума.
- **Коллаборация элитных особей** — обеспечивает обмен лучшими решениями между элитными агентами для ускорения сходимости.

Эти нововведения позволяют улучшить характеристики алгоритма SCSO и делают его более устойчивым к локальным минимумам.
